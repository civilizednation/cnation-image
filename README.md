# cnation-image

아이폰 사진 보관함/파일에서 여러 장을 선택해 **선택한 순서 그대로** 리사이징 & 포맷 변환하는 모바일 웹앱입니다.

빌드 과정 없이 `index.html` 한 장으로 동작하는 순수 클라이언트 앱입니다.

## 기능

- 사진 보관함 또는 파일에서 여러 장 선택 (선택한 순서를 기억해서 그 순서대로 처리/저장)
- 가로 또는 세로 픽셀 중 하나만 입력하면 비율을 유지하며 리사이징
- 출력 포맷: JPG / WEBP / PNG
- 이미지 품질 조절 (기본 80%, PNG는 무손실이라 미적용)
- 변환 후 저장 위치 선택: 사진 보관함(공유 시트로 저장) / 파일(zip 다운로드)
- 이미지 처리는 전부 브라우저(캔버스)에서 수행되어 서버 업로드가 없습니다

## 로컬 실행

설치나 빌드 없이 `index.html`을 정적 서버로 열면 됩니다.

```bash
npx serve .
```

`http://localhost:3000` 을 아이폰 사파리로 접속해 테스트하세요 (같은 네트워크에서 로컬 IP로 접속하거나, Vercel에 배포 후 테스트 추천).

## 홈 화면에 앱처럼 추가하기 (iPhone)

1. 사파리로 배포된 주소 접속
2. 공유 버튼 → "홈 화면에 추가"
3. 아이콘이 지정된 앱 아이콘으로 표시되고, 실행하면 사파리 주소창 없이 전체화면 앱처럼 열립니다

## 배포

정적 파일만 있는 프로젝트라 Vercel에 그대로 배포 가능합니다 (빌드 커맨드 불필요).
